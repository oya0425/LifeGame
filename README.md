🎮 ぴったり目標金額！人生ゲーム（仮）
Unity (Unity 6) で制作した、戦略的ボードゲームシステムです。

🌟 ゲーム概要
従来の「お金を稼ぐだけ」の人生ゲームとは異なり、あらかじめ決めた目標金額に「ぴったり」合わせることを目指す、戦略性の高いボードゲームです。
目標を超えるだけでなく、いかに調整して着地させるかという、リソース管理の駆け引きを楽しめます。

📋 基本情報
コンセプト: 目標金額ちょうどを目指す、逆算型人生ゲーム

プレイ形態: ローカル対戦 / プレイ

開発環境: Unity 6000.2.7f2 (Unity 6)


⚙️ ゲームシステム詳細
1. 厳密なターン制ステートマシン
GameManagerによる状態遷移（State Machine）を最適化し、1ターン内で各状態（State）が正確に1周のみ更新される堅牢なロジックを実装しています。

2. 戦略的目標選択システム
ゲーム開始時に、プレイヤーは提示された4つの選択肢（内容説明あり）から1つを選択します。

ブラインド金額設定: 選択後に具体的な目標金額が判明するため、内容からリスクとリターンを推測する戦略性が生まれます。

勝利条件: 最終的な「目標金額」と「現在の所持金」の差額（絶対値）が最も小さいプレイヤーが勝利となります。

数値バランスの最適化: イベントマスの選択肢によって得られる金額と失う金額のバランスを精査し、最後まで逆転の可能性が残るゲーム性を追求しました。

✨ UX (User Experience) と演出
1. インタラクティブなUIアニメーション
「触っていて気持ちいいUI」を目指し、ゲームで頻出する標準的なUX表現を網羅しています。

Hover演出: ボタンにカーソルを合わせた際のスケールアップ（拡大）処理。

Feedback: プレイヤーの操作に対する視覚的な反応を徹底し、ストレスのない操作感を提供します。

2. サウンド・レジュームシステム

シームレスな音響体験: AudioSource.Pause/UnPause を活用し、イベント発生時にBGMを中断しても、終了後に「続きから」再開される仕組みを構築。

音楽的連続性の維持: 状態遷移のたびにBGMがリセットされる違和感を排除し、長時間のプレイでも没入感を損なわない設計にこだわりました。
